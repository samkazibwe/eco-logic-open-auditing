# Eco-Logic Architecture Overview

## Layer 1: Community Input
Data collected via offline-first tools (ODK / Kobo).

## Layer 2: Secure Relational Database
PostgreSQL database with structured tables and foreign key integrity.

## Layer 3: Governance & Audit Layer
Verification status, data access logs, and role-based permissions.

## Layer 4: GIS & Analytics Layer
QGIS for spatial mapping and Power BI for dashboard reporting.

## Layer 5: Open API Layer (Future)
Designed for integration with Open Supply Hub or other open systems.
